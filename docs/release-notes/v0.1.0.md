## Chess++ 0.1.0 — first release

First public build of Chess++, a chess application with a Qt 6 QML front end and a C++ chess core.

**Download:** [`ChessSetup-0.1.0.exe`](https://github.com/novaua/qt-chess/releases/download/v0.1.0/ChessSetup-0.1.0.exe) (Windows 10/11, x64)

### Highlights

- **Play locally** — two players on one board, with legal-move highlighting, last-move highlighting, check/checkmate detection, castling, en passant and pawn promotion.
- **Play the computer** — connects to any UCI engine (Stockfish recommended) with five difficulty levels. You can play as White or Black. A FEN-based engine communication mode is available in Settings.
- **Play online** — log in with your Lichess account and create online games.
- **User profiles** — local user login, per-user saved games and settings.
- **Game UI** — move history panel, captured-pieces panels, resign / surrender buttons, end-of-game dialog, sound effects with volume control, settings dialog.
- **Installer** — optional one-click download of the latest Stockfish engine into the install folder.

### Installing

1. Download `ChessSetup-0.1.0.exe` from the assets below and run it.
2. Windows SmartScreen will show *"Windows protected your PC"*. The installer and executables are signed with a self-signed certificate, not a commercial one. Click **More info → Run anyway**.
3. On the *Optional components* page, tick **Download latest Stockfish chess engine** to play against the computer out of the box. Otherwise place a UCI engine in `<install dir>\engines\` yourself.

### Known limitations

- Windows x64 only.
- Network multiplayer over LAN (UDP discovery) is not part of this release; online play goes through Lichess.
- The installer is self-signed, so SmartScreen warns on first run.

### Build reference

Built by the **Build Installer** GitHub Actions workflow from the `v0.1.0` tag on `develop` (MSBuild Release|x64, Qt 6.10.2, MSVC 2022, Inno Setup 6). Unit tests (`ChessTests`) must pass before the installer is built.

### What's changed since the project started

Everything below was merged to `develop` between February and June 2026.

**Chess core and engine**
- Checkmate detection fixed, including when the UCI engine replies `bestmove (none)` / `0000`.
- Computer pawn promotion fixed; FEN support for engine communication.
- Engine difficulty levels 1–5 (Stockfish *Skill Level*).
- Play as Black against the computer.

**Online and accounts**
- Lichess online game creation and Lichess site login.
- User management: `users.json`, per-user saves, login screen, popup menu.

**UI**
- New menu and restructured QML/assets, UI panels with captured pieces, history box.
- Settings dialog, basic sound effects and loudness control.
- End-game dialog, surrender buttons, button colour fixes.

**Build and release**
- Toolchain upgrade to Visual Studio 2022 / Qt 6.10.
- GitHub Actions: tests on every push/PR; installer build, code signing and GitHub Release on `v*` tags.
