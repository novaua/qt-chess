## Chess++ 0.1.2

Fixes the optional Stockfish download in the installer and changes which engine the app prefers.

**Download:** [`ChessSetup-0.1.2.exe`](https://github.com/novaua/qt-chess/releases/download/v0.1.2/ChessSetup-0.1.2.exe) (Windows 10/11, x64)

### Fixes

- **Installer: Stockfish download works again.** Stockfish 19 renamed its Windows downloads, so the installer's download link returned 404 and no engine was installed. The installer now tries the current name, then the old name, then a pinned, hash-verified Stockfish 19 build. If every attempt fails, it shows each URL with the reason and where to get Stockfish manually; the app is still installed.
- **Engine selection:** the app now uses the Stockfish installed in its own `engines` folder first, and only falls back to a `stockfish.exe` on your system `PATH`. It also falls back if the installed one fails to start.

### Upgrading

Run the new installer over an existing install. If you installed 0.1.0 or 0.1.1 and have no engine, tick *Download latest Stockfish chess engine* on the optional components page. As before, the installer is signed with a self-signed certificate, so Windows SmartScreen shows a warning: click **More info → Run anyway**.

### Known limitations

- Silent installs (`/SILENT`, `/VERYSILENT`) do not download Stockfish; place `stockfish.exe` in `<install dir>\engines\` yourself.

### Build reference

Built by the **Build Installer** GitHub Actions workflow from the `v0.1.2` tag (MSBuild Release|x64, Qt 6.10.2, MSVC 2022, Inno Setup 6) after the unit tests passed.
