## Chess++ 0.1.1

Maintenance release: licensing, binary metadata and documentation. No gameplay changes.

**Download:** [`ChessSetup-0.1.1.exe`](https://github.com/novaua/qt-chess/releases/download/v0.1.1/ChessSetup-0.1.1.exe) (Windows 10/11, x64)

### What's new

- **Licensed under GPL-3.0.** The license is in the repository and is shown during installation.
- **Version information on the binaries.** `ChessGui.exe` and `LiChessConnector.dll` now carry product name, company, copyright and version (visible under *Properties → Details*). The version is taken from the release tag, and the release build fails if it doesn't match.
- **Documentation.** The README now describes the features, the code signing policy and what network connections the app makes (privacy).
- Installer publisher link corrected.

### Installing

Same as 0.1.0: the installer is signed with a self-signed certificate, so Windows SmartScreen shows a warning. Click **More info → Run anyway**. Tick *Download latest Stockfish chess engine* on the optional components page to play against the computer out of the box.

### Build reference

Built by the **Build Installer** GitHub Actions workflow from the `v0.1.1` tag (MSBuild Release|x64, Qt 6.10.2, MSVC 2022, Inno Setup 6) after the unit tests passed.
